# assets/sfx — 영상 제작용 효과음

출처: `C:\Git\FE-SRPG\public\audio\{sfx,ui}` (자체 제작 게임 SFX). 48 kHz 스테레오 WAV로 변환해 둠.
용도별 이름으로 바꿔 두었으니 브리지/플랜에서 `assets/sfx/<name>.wav`로 참조.

| 파일 | 용도 |
|---|---|
| whoosh_drop, whoosh_short, whoosh_short_2 | 요소 등장·퇴장 휘익 |
| thud, thud_soft | 착지·정착 |
| blip, blip_2, blip_off | 짧은 UI 블립 (자막·라벨 등장) |
| chime_complete, chime_levelup, sparkle_gain | 로고 정착·점수 카드·강조 |
| beacon_light | 밝아지는 강조 |
| ui_open, ui_add, ui_remove, ui_cancel, ui_buy, ui_save_ok, ui_fail | 패널·라벨·전환 |
| turn_end, objective_change, critical_hit | 섹션 전환·임팩트 |

첫 사용: 데모 찍먹 인트로 (2026-09-03).
